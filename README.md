# Zip2mmd

**压缩包里的 MMD 模型，预览即开。**

不用解压、不用装 Python，双击就能看压缩包里的 3D 模型。

![icon](app.ico)

---

## 它解决什么问题

MMD 模型大多是压缩包分发的，想看一眼长什么样，通常得：

```
解压 → 找模型文件 → 打开 PMXEditor / Blender → 等加载 → 看完再删
```

模型一多，这个过程极其难受。Zip2mmd 把这个流程压成一次点击：

**扫描目录 → 双击压缩包 → 点模型 → 直接渲染**

而且可以给每个压缩包存一张封面截图回包里，慢慢就变成一个能滚动的模型库。

---

## 功能

### 预览

- **免解压**：直接从 zip / 7z / rar 里读模型和贴图，不落地临时文件
- **真渲染**：PMX 走 MMD 语义（toon 渐变、sph/spa 球面贴图、semi-transparent），不是找现成缩略图
- 支持格式：`.pmx` `.pmd` `.glb` `.gltf` `.fbx` `.obj`
- 图片灯箱：png / jpg / webp / bmp / gif / tga，dds 自动转码
- 加密压缩包：支持密码，可存密码库一键选用

### 管理

- 左侧**层级目录树**，逐级展开，按目录分组
- 网格 / 列表两种视图，可按「有预览图 / 无预览图 / 加密 / 未加密」筛选
- **批量模式**：全选 / 反选 / 整批拖动 / 批量移动 / 批量生成或删除预览图
- 文件夹和压缩包都能拖到上级目录（最多到管理根目录）
- 右键：新建子文件夹、移动到…、解压、重命名、删除到工具回收站

### 封面

- 右侧「截图」把当前视角存成 PNG，写入包内 `ZipPreview/` 目录
- 自动曝光：按贴图亮度分布校正，避免高光切白
- 网格里直接显示封面，支持自定义环境光颜色

## 使用

### 直接下载 exe

到 [Releases](../../releases) 下载 `Zip2mmd.exe`，双击运行。

首次启动 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可（未做数字签名）。

### 从源码运行

```bash
python app.py
```

需要 Python 3.9+。

### 依赖

- Windows 10 / 11
- **Edge 或 Chrome**（用 `--app` 模式当窗口外壳）
- **7-Zip**（读压缩包；装在哪个盘都行，程序会自动从注册表 / PATH / Program Files 找，也可以在设置里手动指定）

## 构建

```bash
pip install pyinstaller
build.bat
```

产物在 `dist\Zip2mmd.exe`（单文件，解包到 exe 旁边，不碰系统临时目录）。

---

## 已知限制

- 只识别 7-Zip 作为解包引擎（WinRAR / Bandizip 不能替代）
- `.blend` / `.zprj` / `.uemodel` 不能内嵌预览，需要配置外部程序
- 不处理分卷压缩包的后续卷（`.002` / `.003`）
