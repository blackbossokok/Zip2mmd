不用解压、不用装 Python，双击就能看压缩包里的 3D 模型。所有处理都在本机完成，不上传文件。

## 它解决什么问题

MMD 模型大多是压缩包分发的，想看一眼长什么样，通常得：

```
解压 → 找模型文件 → 打开 PMXEditor / Blender → 等加载 → 看完再删
```

模型一多，这个过程极其难受。Zip2mmd 把它压成一次点击：

**扫描目录 → 双击压缩包 → 点模型 → 直接渲染**

还能给每个包存一张封面截图回包里，慢慢就变成一个能滚动的模型库。

## 功能

### 预览

- **免解压**：直接从 zip / 7z / rar 里读模型和贴图
- **真渲染**：PMX 走 MMD 语义（toon 渐变、sph/spa 球面贴图、半透明），按文件自带标准材质渲染，不猜脸、不自动换贴图
- 支持格式：`.pmx` `.pmd` `.glb` `.gltf` `.fbx` `.obj`
- 图片灯箱：png / jpg / webp / bmp / gif / tga（dds 自动转码）
- 加密压缩包：支持密码，可存密码库一键选用
- **嵌套压缩包**：包里的 zip/7z/rar 也能点进去看
- **散文件**：模型、图片、音频、VMD 等散文件也会直接收录，按类型打开，不当压缩包处理
- **VMD 动作预览**：模型 / 动作 / 镜头 / 音频池化管理，多角色绑定，播放条可拖动、循环、调速、调音量；位置完全由 VMD 自带信息决定

### 加载速度

模型加载前会先把包内资源**批量解压**到缓存，贴图不再逐张调 7z：

> 实测 168 MB 的包：14 张贴图从 3.27 s 降到 0.06 s，整体加载约 4 倍提速

### 管理

- 左侧**层级目录树**，支持全层级折叠、全部展开/折叠、定位到目录、折叠父文件夹
- **搜索**：自动定位命中分组、支持全库包内文件名搜索、搜索历史（回车和失焦都会记录）
- **筛选**：类型 / 标签 / 分栏 / 是否重复均支持 Ctrl 加选、Shift 首尾多选；「含包内」同时搜包名和包内文件名
- **收藏**：卡片右上角星标，收藏夹独立入口，移动文件后自动跟随
- **标签**：右键「管理标签…」统一面板。单项直接管理自己的标签；批量显示所有去重标签，重复出现的标为「共有」，× 批量移除，添加和快速标签批量追加，右下角可清除全部
- **排序**：名称 / 大小 / 修改时间
- **分页**：页码 / 跳转 / 每页条数，上万条也不卡
- **批量模式**：工具栏只保留全选、反选、清空、删除、退出批量；压缩包右键动作统一对选中集合生效（定位、打开所在文件夹、移动、复制、标签、预览图、解压、重命名、删除）
- 文件夹和压缩包都能拖到上级目录（最多到管理根目录）
- **文件管理**：压缩包、散文件、文件夹都能重命名、删除、新建、移动
- 快捷键与 Ctrl+C / Ctrl+X / Ctrl+V 剪贴板、撤销、工具回收站、配置与索引备份
- **任务进度与取消**：批量移动、复制、删除、重命名等都有进度条
- **多开隔离**：每个窗口标题带端口，浏览器配置独立，关一个不会影响另一个

### 封面

- 四个生成入口：批量模式、右键压缩包、右键包内模型、视口截图
- 生成时会打开目标模型并等贴图就绪，再正面取景写入包内 `ZipPreview/` 目录
- 包内卡片和外层卡片封面同步刷新，带版本号避免浏览器缓存
- 网格里直接显示封面，可调环境光颜色

## 使用

### 下载 exe

到 GitHub 的 Releases 页面下载 `Zip2mmd.exe`，双击运行。

首次启动 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可（未做数字签名）。

### 从源码运行

```bash
pip install flask
python app.py
```

需要 Python 3.9+。

### 依赖

- Windows 10 / 11
- **Edge 或 Chrome**（用 `--app` 模式当窗口外壳）
- **7-Zip**（读压缩包；装在哪个盘都行，程序会从注册表 / PATH / Program Files 自动找，也能在设置里手动指定）

---

## 构建

```bash
pip install flask pyinstaller
build.bat
```

产物在 `dist\Zip2mmd.exe`（单文件，解包到 exe 旁边，不碰系统临时目录）。

## 已知限制

- 只识别 7-Zip 作为解包引擎（WinRAR / Bandizip 不能替代）
- `.blend` / `.zprj` / `.uemodel` 不能内嵌预览，需要配置外部程序
- VMD 位置完全由动作自带信息决定，不额外叠加程序位移
- VMD 主要面向 PMX / PMD 模型；FBX / GLB / OBJ 不能直接用 VMD 骨骼动画驱动
- 不处理分卷压缩包的后续卷（`.002` / `.003`）
- 不导出模型
